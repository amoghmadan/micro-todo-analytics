# micro-todo-analytics
Micro-services and SDUI to build a distributed system which builds into one.

## Bring All the Submodules.
The following command will help you clone all the submodules which will help you run the project.
- ```bash
  git submodule update --init --recursive
  ```

## Databases
The databases used in this project are available via docker-compose.yaml only for testing.

## PS
`Note`: Adjust all the .env files to make sure you are connected on the right host and ports.
